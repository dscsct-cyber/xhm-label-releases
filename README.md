## 激活

1. 安装并打开 XHM Label。
2. 进入「授权管理」，复制本机机器码。
3. 登录官网账号页，粘贴机器码领取激活码（有效期 10 分钟）。
4. 回到「授权管理」粘贴激活码并点击「在线激活」，激活后可在本机离线使用。

一个激活码仅绑定一台电脑；更换电脑需重新领取对应本机的授权。
